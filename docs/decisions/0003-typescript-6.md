# 0003: TypeScript 6.0

## Kontext

Najnovšia verzia TypeScriptu je 7.0 (natívny kompilátor). `typescript-eslint` 8.71 podporuje iba TypeScript `<6.1.0`, takže s TS 7 by nefungoval type-aware lint.

## Rozhodnutie

TypeScript 6.0.3 v celom monorepe.

## Dôsledky

Prechod na TS 7 je samostatná úloha, keď ho `typescript-eslint` začne podporovať.
