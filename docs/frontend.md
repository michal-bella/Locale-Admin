# Frontend

React SPA na Vite+ (`vp dev`, `vp build`, `vp test`) s Mantine 9, Tailwind 4, TanStack Router a Query, axios a react-i18next.

## Skripty

Spúšťajú sa z rootu cez `pnpm --filter frontend <skript>`.

| Skript           | Čo robí                                                                          |
| ---------------- | -------------------------------------------------------------------------------- |
| `dev`            | dev server na `http://localhost:5173`, `/api` proxuje na `localhost:3000`        |
| `build`          | produkčný build do `frontend/dist`                                               |
| `preview`        | servíruje `dist` na `http://localhost:4173` (s rovnakou `/api` proxy)            |
| `test`           | unit testy (Vitest cez Vite+, prostredie jsdom), súbory `src/**/*.test.{ts,tsx}` |
| `typecheck`      | `tsc --noEmit`                                                                   |
| `generate-icons` | vygeneruje React komponenty ikon zo SVG (viď Ikony)                              |
| `generate-flags` | vygeneruje React komponenty kruhových vlajok zo SVG (viď Vlajky)                 |

## Routing

TanStack Router s routami v kóde (ADR 0002), jeden súbor na routu v `routes/`. Root route má kontext s `queryClient`.

| Cesta                                 | Route                                         | Stránka                                               | Prístup                                  |
| ------------------------------------- | --------------------------------------------- | ----------------------------------------------------- | ---------------------------------------- |
| `/login`                              | `loginRoute`                                  | `LoginPage`                                           | iba neprihlásený (prihlásený ide na `/`) |
| `/`                                   | `indexRoute` pod `_home`                      | `ProjectsPage` (zoznam projektov, bez sidebaru)       | prihlásený                               |
| `/profile`                            | `profileRoute` pod `_app`                     | `ProfilePage` (Môj profil)                            | prihlásený (`ADMIN` aj `EDITOR`)         |
| `/admin/projects`                     | `adminProjectsRoute` pod `_app`               | `AdminProjectsPage` (správa všetkých projektov)       | `ADMIN`, ostatní vidia `ForbiddenPage`   |
| `/admin/users`                        | `adminUsersRoute` pod `_app`                  | `UsersPage` (všetci používatelia, vytvorenie s rolou) | `ADMIN`, ostatní vidia `ForbiddenPage`   |
| `/admin/users/$userId`                | `adminUserRoute` pod `_app`                   | `UserPage` (detail používateľa a jeho projekty)       | `ADMIN`, ostatní vidia `ForbiddenPage`   |
| `/projects/$projectSlug`              | `projectIndexRoute` pod `projectRoute`        | presmeruje na `/projects/$projectSlug/translations`   | člen projektu alebo `ADMIN`              |
| `/projects/$projectSlug/translations` | `projectTranslationsRoute` pod `projectRoute` | `TranslationsPage` (Preklady), filtre v URL           | člen projektu alebo `ADMIN`              |

| `/projects/$projectSlug/settings`     | `projectSettingsRoute` pod `projectRoute`     | `ProjectSettingsPage` (Nastavenia projektu)           | člen projektu alebo `ADMIN`              |
| `/projects/$projectSlug/languages`    | `projectLanguagesRoute` pod `projectRoute`    | `ProjectLanguagesPage` (Jazyky projektu)              | člen projektu alebo `ADMIN`              |
| `/projects/$projectSlug/versions`     | `projectVersionsRoute` pod `projectRoute`     | `ProjectVersionsPage` (Verzie prekladov)              | člen projektu alebo `ADMIN`              |

Strom: `_authenticated` (načíta používateľa, bez komponentu) → `_home` (`HomeLayout`, iba `/`) a `_app` (`AppLayout` so sidebarom, ostatné stránky). `projectRoute` (`/projects/$projectSlug`) je pod `_app`.

Chyba v `beforeLoad` alebo v komponente routy bez vlastného `errorComponent` zobrazí `ErrorPage` (`defaultErrorComponent` routera).

### Lazy routy (code splitting)

Komponenty stránok `/login`, `/profile`, `/admin/projects`, `/admin/users`, `/admin/users/$userId`, prekladov, prehľadu, nastavení, jazykov a členov projektu sa načítajú až pri prvej návšteve routy. Route súbor (`loginRoute.ts`, `adminUsersRoute.ts`) drží iba kritickú časť (`path`, `beforeLoad` guard, pri `/admin/projects`, `/admin/users` a `/admin/users/$userId` aj `errorComponent`, aby sa 403 zobrazila bez čakania na chunk stránky) a cez `.lazy(() => import('@/routes/<route>.lazy').then((module) => module.Route))` pripojí súbor `<route>.lazy.ts`, ktorý obsahuje `createLazyRoute('<route id>')({ component })`. Route id je cesta vrátane pathless rodičov (`/_authenticated/_app/admin/users`), typecheck preklep v id zachytí. `ProjectsPage` (prvá stránka po prihlásení) a stránky 404, 403 a chybová stránka ostávajú v hlavnom chunku.

Knižnice sú v samostatných chunkoch cez `build.rolldownOptions.output.codeSplitting.groups` vo `vite.config.ts`: `react` (react, react-dom, scheduler), `mantine` (`@mantine/*` okrem `@mantine/charts`), `tanstack` (`@tanstack/*`) a `i18n-zod` (i18next, react-i18next, zod). Menia sa iba pri aktualizácii závislostí, takže ich prehliadač drží v cache aj po novom release aplikácie. Ostatné knižnice delí rolldown automaticky, takže tie, ktoré používajú iba lazy stránky (React Hook Form, resolver), ostávajú v lazy chunkoch. `chunkSizeWarningLimit` sa nemení.

### Guardy

- `_authenticated` je pathless route (bez segmentu v URL) bez vlastného komponentu; layout dodávajú jej deti `_home` (`HomeLayout`) a `_app` (`AppLayout`). Jej `beforeLoad` zavolá `queryClient.ensureQueryData(meQueryOptions)`. Pri 401 presmeruje na `/login` (bez `?redirect=`), iné chyby (5xx, nedostupný backend) pustí ďalej a zobrazí sa `ErrorPage`. Načítaného používateľa vráti do kontextu ako `context.user` pre podriadené routy.
- `/login`: `beforeLoad` skúsi načítať `me`. Ak sa podarí, presmeruje na `/`. Akákoľvek chyba (401, nedostupný backend) znamená, že sa zobrazí formulár.
- `/projects/$projectSlug`: URL obsahuje slug projektu, API ostáva na id. `loader` nájde id podľa slugu v zozname projektov (`ensureQueryData(projectsQueryOptions)`, zoznam obsahuje práve projekty, ktoré používateľ smie otvoriť). Ak slug v uloženom zozname nie je (projekt vytvorený alebo premenovaný po načítaní zoznamu), načíta zoznam raz nanovo (`fetchQuery` so `staleTime: 0`). Potom zavolá `ensureQueryData(projectSettingsQueryOptions(projectId))` bez opakovaní a vráti `{ projectId }` (stránky ho čítajú cez `useLoaderData`, sidebar cez `useMatch`). Neznámy slug alebo `404 NOT_FOUND` (projekt neexistuje alebo používateľ nie je členom) vyhodí `notFound()` a vnútri `AppLayout` sa zobrazí `ProjectNotFoundPage` („Projekt sa nenašiel“, **Späť na projekty**). Iná chyba zobrazí `ErrorPage` cez `RouteError`. Rolu neoveruje, prístup rozhoduje BE.
- `/admin/projects`, `/admin/users` a `/admin/users/$userId`: `beforeLoad` pre rolu inú ako `ADMIN` vyhodí `ForbiddenError`. `errorComponent` (`RouteError`) pre túto chybu zobrazí `ForbiddenPage` vnútri layoutu a URL ostáva rovnaká. Iné chyby zobrazí `ErrorPage` vnútri layoutu.
- `/projects/$projectSlug/settings`, `/languages`, `/versions` a `/members`: rovnaký guard pre rolu `VISITOR` (Návštevník má iba Preklady a Prehľad; API mu dáta týchto stránok číta, blokuje ich iba aplikácia). Plán: [visitor-role.md](./plans/visitor-role.md).
- Po prihlásení ide `ADMIN` aj `EDITOR` na `/`.

Produkčný server (nginx) musí pre neznáme cesty vrátiť `index.html` (SPA fallback), inak refresh na hlbokej route skončí chybou servera.

## API

- Jediná axios inštancia `api/http.ts`: `baseURL: '/api'`, `withCredentials: true`.
- Interceptor posiela pri každej požiadavke `X-Requested-With: XMLHttpRequest`. Mutácie (`POST`, `PUT`, `PATCH`, `DELETE`) bez tela pošlú `{}`, aby odišla hlavička `Content-Type: application/json` (ochrana proti CSRF na BE).
- Query kľúče sú iba v `QUERY_KEYS` (`api/queryKeys.ts`).
- `getApiErrorCode(error)` vráti `ERROR_CODE` z odpovede podľa `errorResponseSchema` z `@locale/shared`, inak `UNKNOWN`. Text chyby sa zobrazuje iba cez preklad `errors.<CODE>`, nikdy z `message`. `getApiErrorDetails(error)` vráti `details` z `VALIDATION_ERROR` (inak prázdne pole), `getImportFileIssues(error)` vráti `{ issues, total }` z `422 IMPORT_FILE_INVALID` (inak `null`), `getPlaceholderMismatch(error)` vráti `{ missing, extra }` z `400 PLACEHOLDER_MISMATCH` (inak `null`).
- `queryClient` neopakuje dotazy, ktoré skončili 401 (ostatné chyby najviac 3-krát). Výnimkou je `me` (`retry: false`): guardy naň čakajú pred zobrazením stránky a opakovanie s backoffom by pri 5xx alebo výpadku siete blokovalo stránku asi 7 s.

### Prihlásenie a session

| Hook / funkcia                   | Čo robí                                                                                                                                                                     |
| -------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `meQueryOptions`, `useMeQuery`   | `GET /api/auth/me`, kľúč `QUERY_KEYS.AUTH.ME()`, `staleTime: Infinity`, `retry: false` (načítajú ho guardy, drží sa do odhlásenia alebo 401)                                |
| `useLoginMutation`               | `POST /api/auth/login`, odpoveď (`AuthUser`) uloží do `me` a naviguje na `/`                                                                                                |
| `useLogoutMutation`              | `POST /api/auth/logout` bez tela, potom `queryClient.clear()` a navigácia na `/login`                                                                                       |
| `installUnauthorizedInterceptor` | response interceptor (zapína sa v `main.tsx`): pri 401 zavolá `queryClient.clear()` (ako odhlásenie, dáta predošlého používateľa neostanú v cache) a router ide na `/login` |

Interceptor ignoruje `/auth/login` (zlé heslo je chyba formulára) a `/auth/me` (401 z neho riešia guardy samy, inak by sa navigovalo dvakrát). Session cookie (`locale_session`, httpOnly) FE nečíta, posiela ju prehliadač.

### URL search params

Filtre sú v URL (`validateSearch` zod schémou `translationsSearchSchema` v `routes/projectTranslationsRoute.ts`), prežijú reload a dajú sa zdieľať. Každý parameter je voliteľný, neplatná hodnota sa zahodí (`.catch(undefined)`) a použije sa predvolená. Predvolené hodnoty sa do URL nezapisujú.

| Parameter          | Hodnota                                              | Predvolená                                              |
| ------------------ | ---------------------------------------------------- | ------------------------------------------------------- |
| `search`           | text, najviac 200 znakov                             | bez vyhľadávania                                        |
| `status`           | `TRANSLATED`, `UNTRANSLATED`                         | všetky stavy                                            |
| `namespace`        | názov namespace                                      | všetky                                                  |
| `sort`             | `UNTRANSLATED_FIRST`, `KEY`, `UPDATED`               | `UNTRANSLATED_FIRST`                                    |
| `source`           | tag jazyka projektu (`sk`)                           | základný jazyk                                          |
| `target`           | tag jazyka projektu (`en`)                           | prvý jazyk iný ako zdrojový, pri jednom jazyku zdrojový |
| `languages`        | pole tagov (`["en","hu"]`), iba rozšírené zobrazenie | všetky jazyky; základný sa zobrazí vždy                 |
| `updatedBy`        | UUID používateľa                                     | ktokoľvek                                               |
| `updatedWithin`    | `DAY`, `WEEK`, `MONTH`                               | kedykoľvek                                              |
| `version`          | UUID verzie projektu                                 | bez filtra; úpravy idú do aktuálnej verzie podľa dátumu |
| `translationsOnly` | `true` (iba frontend, do API nejde)                  | stĺpce Kľúč a Stav sa zobrazujú                         |
| `pageSize`         | 25, 50, 100                                          | 25                                                      |
| `page`             | číslo strany od 1                                    | 1                                                       |

Jazyky sú v URL ako tagy (čitateľnejší odkaz ako UUID), stránka ich preloží na `sourceLanguageId` a `targetLanguageId` pre API; v rozšírenom zobrazení sa `source` a `target` ignorujú (dotaz ide bez jazykov) a ostávajú v URL pre prepnutie späť. Tag, ktorý projekt nemá, sa ignoruje. Každá zmena filtra vráti stranu na 1 a nahradí položku histórie (`replace`); `languages` a `translationsOnly` menia iba stĺpce, stranu nechajú. `languages` mení iba stĺpce: stav riadku, filter stavu, zoradenie a štatistiky ostávajú počítané cez všetky jazyky projektu a parameter do API nejde. `updatedBy` a `updatedWithin` idú do API ako `updatedById` a `updatedWithin`. **Zrušiť filtre** (pri prázdnom výsledku) zruší vyhľadávanie, stav, namespace, Editor a Zmenené, výber jazykov a Len preklady nechá. Ak je v URL aktívny filter `namespace`, select sa zobrazí, aj keď má projekt najviac jeden namespace, aby aktívny filter nebol neviditeľný. Strana za koncom (`?page=99` alebo posledná strana sa zmenšila) presmeruje na poslednú stranu namiesto stavu „nič nenájdené“. Vyhľadávanie má `maxLength` 200 (`TRANSLATIONS_SEARCH_MAX_LENGTH`). Namespace `""` (kľúče bez namespace) sa vo filtri neponúka, lebo API berie prázdny reťazec ako „bez filtra“.

Odchýlky od Figmy: chýba **Exportovať**, „Posledný sync“, karta a stav **Na kontrolu** a stav **Chýba** (stavy sú iba dva), drobčeky; pribudli filtre namespace a zoradenie a výber cieľového jazyka. Prázdny cieľ ukazuje „Bez prekladu“ namiesto „Pridať anglický preklad…“. Polia toolbaru majú výšku 44 px z theme (Figma 40 px). Relatívny čas je z `Intl` bez bodky („pred 2 min“, Figma „pred 2 min.“).

### Verzie na stránke Preklady

Verzia prekladov (plán [`translation-versions.md`](./plans/translation-versions.md), [API: verzie projektu](./api/project-versions.md)) sa na stránke Preklady prejaví iba v projekte, ktorý nejakú má (`useProjectVersionsQuery`); bez verzií stránka vyzerá a posiela to isté ako predtým.

- **Filter Verzia** v `TranslationsToolbar` (`Select` s možnosťou zrušiť, placeholder **Všetky verzie**, položky podľa `startsAt` zostupne, aktuálna ako „v2.45 (aktuálna)“) zapíše `?version=<id>` a do API `versionId` (práca verzie: kľúče vzniknuté v nej alebo s bunkou naposledy zapísanou v nej). **Bez parametra je predvolená aktuálna verzia** (od 2026-10-22; stránka sa otvára na práci, ktorú editori dokončujú), zrušenie filtra zapíše `?version=ALL` = celý projekt (`ALL_VERSIONS` v `projectTranslationsRoute`). Karty štatistík počítajú celý projekt, preto klik na kartu aj **Zrušiť filtre** nastavia `ALL`; v projekte bez verzií ostáva URL bez parametra.
- **Chip verzie** pri kľúči (`item.version`): názov verzie v tlmenom chipe v štýle odznaku Základný, prístupné meno „Vznikol vo verzii {{name}}“.
- `TranslationsVersionBanner`: Mantine `Alert` na povrchu karty (`--app-color-surface`, text `--app-color-text-secondary`, lebo Mantine sivá `gray-light` je v tmavej schéme takmer čierna a bije sa so slate kartami; ikona `Tag`, pri uzamknutej verzii modrý s ikonou `Lock`) nad bannerom upozornení pre verziu z filtra, inak pre aktuálnu verziu podľa dátumu: „Verzia v2.45: ostáva 12 dní do uzamknutia.“ (plurál `translationsPage.version.remaining`, posledný deň „dnes je posledný deň, potom sa uzamkne“), pred začiatkom „začína o N dní“, po termíne odomknutá „je po termíne odomknutá na dodatočné úpravy“, uzamknutá „je uzamknutá“ a pre editora „…, jej preklady upravuje už len administrátor“. Dni sa počítajú z `YYYY-MM-DD` a dnešného dátumu v prehliadači (`daysUntil`, `toVersionDate` zo `@locale/shared`). Za odpočtom banner povie, koľko kľúčov z práce verzie je ešte nepreložených („Nepreložených ostáva 37 kľúčov.“, plurál `translationsPage.version.untranslated`; pri nule nič): druhý dopyt `GET …/translations` s `versionId`, `status=UNTRANSLATED` a `pageSize=1`, číta sa len `total` (v kompaktnom zobrazení s dvojicou jazykov, takže počet zodpovedá tomu, čo by filter ukázal). Tlačidlo **Zobraziť prácu verzie** zapne filter, **Zrušiť filter verzie** ho vypne.
- **Vytvoriť verziu** (`ADMIN`, tlačidlo s ikonou `Tag` vedľa Pridať kľúč) otvorí ten istý `VersionFormModal` ako stránka Verzie; po vytvorení sa nová verzia hneď zapne vo filtri (`?version=<id>`), takže ďalšia práca na stránke ide do nej.
- **Zamknúť** / **Odomknúť** v banneri verzie (`ADMIN`, ikona `Lock` / `LockUnlocked`, prístupné meno „Zamknúť verziu {{name}}“ / „Odomknúť verziu {{name}}“) otvorí `VersionLockModal` pre verziu bannera (z filtra, inak aktuálnu), rovnako ako na stránke Verzie.
- **Zápisy**: `useUpdateTranslationMutation` a `CreateKeyModal` posielajú `versionId` z filtra; bez filtra API vyberie aktuálnu verziu podľa dátumu. Pri uzamknutej verzii vo filtri dostane `EDITOR` tabuľku iba na čítanie (`readOnly`, bunky sú text, modál sa neotvorí), lebo API by zápis odmietlo 409 `PROJECT_VERSION_LOCKED`; `ADMIN` upravuje ďalej. Chyba `PROJECT_VERSION_LOCKED` z API sa prekladá ako každý kód.

### Modál Upraviť preklad

`EditTranslationModal` (`components/EditTranslationModal/`) otvára klik na bunku prekladu (`TranslationCell`); Návštevníkovi (`readOnly` tabuľky) sa bunka vykreslí ako `div` s rovnakým vzhľadom bez kurzora a hoveru, nie ako tlačidlo, a modál sa nerenderuje, takže v riadku nie je nič fokusovateľné; úprava priamo v riadku a uloženie klikom mimo pole sa odstránili (preklady bývajú dlhé a modál dá miesto aj kontextu). Modál nemá Figmu, zdrojová bunka ostáva iba na čítanie.

- **Bunka** (`TranslationCell`): natívne `<button>` s hodnotou (`TranslationValue`: premenné `{{…}}` ako chip, plurálové formy pod sebou, alebo **Bez prekladu**). Prístupné meno je „Preklad kľúča orders.empty.title, English: Welcome back, {{name}}“ (skrytý prefix `VisuallyHidden` + viditeľná hodnota; jazyk je pôvodný názov jazyka bunky). Klik, Enter alebo medzerník otvoria modál.
- **Obsah** (`AppModal`, nadpis **Upraviť preklad**): **Kľúč** (monospace, pod ním popis kľúča), **🇸🇰 Základný jazyk (slovenčina)** s hodnotou základného jazyka iba na čítanie (pole má aspoň 42 px ako pole prekladu) ako nápoveda pre prekladateľa (blok chýba, keď sa upravuje samotný základný jazyk), **Preklad** (pred labelom vlajka 16 px, za ním tlmene a bez tučného písma názov upravovaného jazyka v zátvorke, rovnako pri **Základný jazyk**; samostatný blok Jazyk nie je) s [`TokenEditor`](#editor-s-uzamknutými-tokenmi) (`contenteditable`, `role="textbox"`, `aria-multiline`, premenné a HTML tagy uzamknuté, maximálne 10 000 znakov `TRANSLATION_VALUE_MAX_LENGTH` cez `data-maxlength`), tlačidlá **Zrušiť** a **Uložiť**. Prístupné meno poľa „Preklad kľúča orders.empty.title, English“, skrytá veta „Premenné a HTML značky sú zamknuté, mažú sa celé.“ (pri plurále aj „Znak # je miesto čísla.“) cez `aria-describedby`. Pole fokusuje focus trap Mantine cez `data-autofocus` (`TokenEditor` prop `modalAutofocus`, kurzor na konci); `focusOnMount` by vzal fokus skôr, než si Mantine zapamätá tlačidlo bunky, a fokus by sa po zatvorení nemal kam vrátiť. Obsah modálu má `key` z kľúča a jazyka, takže každé otvorenie začína s uloženou hodnotou (zrušený návrh sa zahodí).
- **Plurálový kľúč** (`plural !== null`): jeden `TokenEditor` na každú formu jazyka s chipom názvu formy vľavo (prístupné meno „Preklad kľúča items.count, English, Jeden“ – `translationsPage.editor.formLabel`), `#` je tiež chip; blok základného jazyka ukazuje jeho formy. Uloženie zloží jednu ICU správu `serializePluralValue(variable, forms)`; prázdna forma ostáva ako prázdny reťazec (`one {}`), všetky prázdne → `null`. Pred odoslaním sa formy overia bez requestu: vyvážené `{` a `}` (`hasBalancedBraces`; chybná forma `aria-invalid`, `role="alert"` „Zátvorky { a } musia byť vyvážené.“) a limit 10 000 znakov pre celú správu (všetky formy `aria-invalid`, „Preklad je príliš dlhý (max. 10 000 znakov spolu za všetky formy).“).
- **Uloženie** iba tlačidlom **Uložiť**. Prázdny alebo iba biely text pošle `null` (**Nepreložené**). Rovnaká hodnota ako predtým nepošle nič a modál sa zavrie. Počas requestu je pole `readOnly`, **Uložiť** má loader, **Zrušiť**, X aj Esc sú vypnuté (`isPending`); odznak stavu, pozadie bunky aj karty sa menia hneď (optimisticky, `useUpdateTranslationMutation`). Po úspechu sa modál zavrie, skrytý `role="status"` na stránke oznámi „Uložené: orders.empty.title“ a Mantine vráti fokus na tlačidlo bunky. Obyčajný Enter v poli vloží nový riadok.
- **Prevziať zo základného jazyka**: `RowAction` s ikonou `Copy` vpravo na riadku nadpisu **Základný jazyk (slovenčina)** (prístupné meno „Prevziať text zo základného jazyka (slovenčina) do prekladu“), iba keď má základný jazyk hodnotu. Prepíše návrh v poli textom základného jazyka, aby prekladateľ začal so správnym formátom (premenné, HTML), a dá fokus do prvého pola; nič neukladá. Pri plurálovom kľúči dostane každá forma cieľového jazyka rovnomennú formu základného jazyka, chýbajúca forma jeho formu Other.
- **Uložiť a ďalší** (vpravo od **Uložiť**, ktoré je vtedy `variant="default"`): ukáže sa, keď je na aktuálnej strane po upravovanej bunke ešte nepreložená bunka (poradie čítania: riadky zhora, v rozšírenom zobrazení jazyky zľava, v kompaktnom iba cieľový jazyk). Uloží a modál ostane otvorený s ďalšou bunkou, fokus prejde do jej poľa (`focusOnSwitch`). Tooltip vysvetľuje skratku. `Cmd+Enter` / `Ctrl+Enter` v poli robí to isté; bez ďalšej bunky uloží a zavrie (`aria-keyshortcuts` je na tlačidle, ktoré skratka spustí). Bunku na ďalšej strane neotvorí.
- **Posledná úprava** v pätičke vľavo: „Posledná úprava: Martin Kováč, pred 5 minútami“ z `updatedBy` a `updatedAt` bunky (relatívny čas, presný dátum a čas v `title`); pri zmazanom používateli iba čas, pri bunke bez riadku nič.
- **Zrušiť**, X a **Esc** zavrú modál bez requestu.
- **`400 PLACEHOLDER_MISMATCH`** (zapnutá ochrana premenných): modál ostáva otvorený, fokus sa vráti do prvého chybného poľa (**Uložiť** je počas requestu `disabled`, inak by fokus skončil na `body`), pole `aria-invalid` a pod ním `role="alert"` „Premenné v preklade sa nezhodujú so základným jazykom. Chýbajú: {{name}}. Navyše: {{user}}.“ (`errors.PLACEHOLDER_MISMATCH` + `translationsPage.editor.missing/extra`, helper `api/getPlaceholderMismatch.ts`); zoznam sa vráti na pôvodnú hodnotu. Písanie hlášku zmaže, ďalšie **Uložiť** skúsi znova.
- **`400 VALIDATION_ERROR`** s `details [{ path: 'value', code: 'INVALID' }]` (backend nevie plurálovú hodnotu parsovať): rovnako, s hláškou „Zátvorky { a } musia byť vyvážené.“ (helper `api/getApiErrorDetails.ts`).
- **Iná chyba** (`404 TRANSLATION_KEY_NOT_FOUND`, `500` …): červená notifikácia `errors.<CODE>`, modál ostáva otvorený s návrhom, zoznam aj karty sa vrátia na pôvodnú hodnotu.
- **Tab**: pre člena v riadku nie sú iné fokusovateľné prvky (kľúč, zdroj ani odznak stavu), takže Tab ide z bunky rovno na bunku ďalšieho riadku. Pre `ADMIN` je pred bunkou ešte tlačidlo **Upraviť kľúč** ďalšieho riadku.

### Editor s uzamknutými tokenmi

`TokenEditor` (`components/TokenEditor/`) je vlastný textový editor nad `contenteditable` (Mantine nemá vhodný wrapper, `Textarea` nevie zamknúť časť textu). Používa ho [modál Upraviť preklad](#modál-upraviť-preklad).

- **Tokeny** (`tokens.ts`, `tokenize(value, { tags, hash })`): `{{var}}` a `{{ var }}` (rovnaký vzor ako `TranslationText` a kontrola premenných na BE), HTML tagy `<strong>`, `</strong>`, `<br/>`, `<a href="…">` (každé `<…>` začínajúce písmenom) a pri plurálových formách `#`. Spojenie hodnôt tokenov vracia presne pôvodný reťazec; `tokenize` zdieľa aj `TranslationText`.
- **Chipy**: `<span contenteditable="false" data-token="{{var}}">` – premenné a `#` v chipe `TranslationText` (ružový), tagy v tlmenom monospace chipe (`--app-color-surface-muted`, `--app-color-text-secondary`). S `basePlaceholders` (modál ich počíta z rovnakej referencie ako tabuľka) má chip premennej mimo základného jazyka triedu `chipWarning` (`render(..., decorate)` v `editorDom.ts`). Natívny `title` sa v `contenteditable` nezobrazuje, preto editor pri `mouseover` na takom chipe položí neviditeľnú kotvu (`warningAnchor`, absolútne nad chipom v obale `wrapper`) a nad ňou otvorí Mantine `Tooltip` s `translationsPage.editor.unknownVariable`; `mouseleave` ho zavrie. Kurzor do chipu nevojde, text sa píše iba medzi nimi. Vedľa chipu na začiatku, konci alebo medzi dvoma chipmi je textový uzol so zero-width space (U+200B), aby sa tam dal postaviť kurzor; serializácia ho nikdy nevráti.
- **Riadenie** (`editorDom.ts`): po každom `input` sa DOM serializuje (`serialize`: textové uzly, `data-token` chipov, `<br>` a bloky prehliadača ako `\n`), hodnota sa orezá na `maxLength`, DOM sa znova postaví z tokenov a kurzor sa vráti podľa offsetu v serializovanom reťazci (`selectionOffsets`, `setCaret`; pozícia vnútri chipu sa počíta ako za ním). Prehliadačom vložené značky tak nikdy neprežijú a hodnota vždy zodpovedá reťazcu. Počas IME skladania (`compositionstart` – `compositionend`) sa nič neprestavuje. Zmena `value` zvonku (napr. Esc a znovuotvorenie) prestaví obsah, kurzor ide na koniec, ak je editor fokusovaný. Daň: prehliadačový Undo (Ctrl+Z) nefunguje.
- **Klávesy**: Backspace tesne za chipom a Delete tesne pred chipom zmažú celý chip (`preventDefault`, kurzor na jeho miesto); inde sa nechá prehliadač a následný `input` prestaví DOM. Enter (aj Shift+Enter) vloží `\n`; Ctrl/Cmd+Enter nič nevloží a nechá ho rodičovi (`onKeyDown` rodiča beží prvý a jeho `preventDefault` vypne vlastné spracovanie); modál Upraviť preklad ho nepoužíva, ukladá sa iba tlačidlom. Pri `maxLength` sa tlačiteľný znak bez modifikátora na plnej hodnote zahodí.
- **Vloženie**: `paste` sa zachytí, vloží sa iba `text/plain` na miesto výberu (orezané na `maxLength`), tokeny vo vloženom texte sa hneď stanú chipmi. Drop je zakázaný.
- **Prístupnosť**: `role="textbox"`, `aria-multiline="true"`, `aria-label`, `aria-describedby`, `aria-invalid`, `aria-readonly` (počas ukladania `contenteditable="false"`, fokus ostáva), `contenteditable="plaintext-only"`, `spellcheck="false"`.
- **Testy** (`tokens.test.ts`, `editorDom.test.ts`, `TokenEditor.test.tsx`): tokenizácia a spätné spojenie, serializácia ↔ DOM, offset kurzora, mazanie chipov, Enter, paste, `maxLength`, `readOnly`. jsdom má Selection a Range, ale skutočné písanie a pohyb kurzora v prehliadači pokryjú E2E testy.

### Plurálové formy

Kľúč s `plural: { variable }` ukladá v každom jazyku jednu ICU správu `{count, plural, one {# položka} few {# položky} other {# položiek}}` (`serializePluralValue` / `parsePluralValue` v `packages/shared/src/plurals.ts`).

- `PluralForms` (`components/PluralForms/`) zobrazí formy pod sebou ako Tolgee: chip s CLDR názvom formy (`PluralFormChip`: **One**, **Few**, **Many**, **Other**; preložený názov „Jeden“, „Málo“, „Veľa“, „Iné“ je v `title`, kľúče `translationsPage.plural.forms.*`) a text formy cez `TranslationText` s `pluralHash`, takže `#` aj `{{…}}` sú chipy; chip `#` má `title` „Číslo“ (aj v editore).
- Zobrazené formy (`lib/pluralForms.ts`, `pluralFormsOf(tag, forms)`) sú formy jazyka z `pluralFormsForTag(tag)` (`Intl.PluralRules` pre celé čísla 0 – 1000 a 1 000 000 plus vždy `other`: sk a cs `one`, `few`, `other`; ru a pl `one`, `few`, `many`, `other`; en `one`, `other`; forma `many` v sk a cs platí iba pre desatinné čísla, počet je celé číslo) zjednotené s formami uloženými v hodnote, v poradí `PLURAL_FORMS`, aby sa uložená forma nikdy neskryla ani nestratila. Chýbajúca forma ukáže tlmené **Bez prekladu**. Hodnota, ktorá nie je plurálová ICU správa (`parsePluralValue` vráti `null`, napr. text spred zapnutia plurálu), sa ukáže ako jediná forma **Other** (`parsePluralForms`). Hodnota `null` ukáže iba **Bez prekladu** ako pri obyčajnom kľúči.
- Úprava foriem je v [modáli Upraviť preklad](#modál-upraviť-preklad), zapnutie a vypnutie plurálu v [modáli Upraviť kľúč](#modál-upraviť-kľúč).

### Modál Importovať preklady

Import ochranu neuplatňuje, nezhodu iba vypíše ako upozornenie.
- Pätička: vľavo **Opustiť projekt** (`Button variant="outline"`, otvorí `LeaveProjectModal`, po odchode presmeruje na `/`), vpravo **Uložiť zmeny**. V modáli Upraviť projekt je vľavo namiesto neho **Zrušiť** (`Button variant="default"`, prop `onCancel`, zatvorí modál). `ADMIN`, ktorý nie je členom (podľa `isMember` zo zoznamu projektov), tlačidlo Opustiť projekt nevidí.

Disabled, kým sa formulár nezmení, počas requestu `loading` a druhé odoslanie sa ignoruje. Úspech → zelená notifikácia „Nastavenia projektu boli uložené.“ a `reset` na hodnoty z odpovede. `400 VALIDATION_ERROR` → `setError` pri poliach podľa `details`, `409 SLUG_TAKEN` → chyba pri slugu, iná chyba (napr. `404 NOT_FOUND`) → červená notifikácia `errors.<CODE>`.
- Stavy mimo Figmy: načítavanie jazykov (2 `Skeleton` vo výške kariet, `aria-busy`), chyba načítania jazykov (nastavenia už načítal loader routy) (text „Nastavenia projektu sa nepodarilo načítať.“, `errors.<CODE>` a **Skúsiť znova**, ktoré znova načíta, čo zlyhalo, a po úspechu dá fokus na Názov projektu). ### Relatívny čas

`lib/formatRelativeTime.ts`: `formatRelativeTime(isoDate, language, now?)` cez `Intl.RelativeTimeFormat` (`numeric: 'auto'`) s rovnakým mapovaním jazyka ako `formatDate` (`toIntlLocale`: `sk` → `sk-SK`, `en` → `en-GB`, neznámy → `sk`). Vyberie najväčšiu jednotku, ktorá sa zmestí (rok 365 dní, mesiac 30 dní, týždeň, deň, hodina, minúta, sekunda), a zaokrúhli: `pred 3 mesiacmi` / `3 months ago`, `včera` / `yesterday`, `teraz` / `now`. ## i18n

- react-i18next, jazyky `sk` (predvolený aj záložný) a `en`, kľúče v objektovej štruktúre (`notFoundPage.title`).
- Zvolený jazyk sa číta z `localStorage` (kľúč `locale`). Ak `localStorage` nie je dostupný alebo hodnota nie je platná, použije sa `sk`. Pri zmene jazyka sa hodnota uloží a aktualizuje sa `<html lang>`.
- Chyby API: `errors.<ERROR_CODE>` a `errors.UNKNOWN`. Validácia: `validation.<VALIDATION_CODE>`, pri `TOO_SHORT` a `TOO_LONG` s parametrami `{{min}}` a `{{max}}`.
- Unit test `lib/i18n.test.ts` overí, že každý `ERROR_CODE` a `VALIDATION_CODE` z `@locale/shared` má preklad v `sk`, `cs` aj `en`, že `sk.json`, `cs.json` a `en.json` majú rovnakú sadu kľúčov (chyba vypíše chýbajúce kľúče pre každý jazyk) a že žiadna hodnota nie je prázdny reťazec. Množné tvary (`kľúč_one`, `_few`, `_many`, `_other`) sa porovnávajú podľa základného kľúča, lebo `sk` a `cs` majú viac tvarov ako `en`; test zároveň overí, že každý množný kľúč má všetky tvary, ktoré jazyk podľa `Intl.PluralRules` potrebuje.
- Unit test `lib/i18nStorage.test.ts` načíta `lib/i18n` vždy nanovo (`vi.resetModules`) a overí, že uložený `en` sa použije, neplatná hodnota a výnimka z `getItem` vrátia `sk` a výnimka zo `setItem` nezhodí zmenu jazyka.
- Prepínač jazyka ukazuje vlajky z balíka `country-flag-icons` (MIT, React SVG komponenty `country-flag-icons/react/3x2`): `SK` pre slovenčinu, `CZ` pre češtinu, `GB` pre angličtinu (angličtina používa britské formáty `en-GB`, čeština `cs-CZ`). Vlajka má 16 px na šírku (pomer 3 : 2), radius 2 px a 1px prstenec `--app-color-border`, aby boli biele časti vidieť aj vo svetlej schéme. ## Farebné schémy

Svetlá (predvolená, podľa Figmy) a tmavá schéma cez vstavanú podporu Mantine. Tmavá schéma nie je vo Figme, je odvodená zo `slate` palety. Voľba „auto“ (podľa systému) v UI nie je.

- Prepína sa tlačidlom `ThemeSwitcher` v hornej lište (Mantine `ActionIcon` 38 × 38 px, ikona 18 px `--app-color-muted`). Vo svetlej schéme ukazuje mesiac s menom **Prepnúť na tmavý režim** / **Switch to dark mode**, v tmavej slnko s menom **Prepnúť na svetlý režim** / **Switch to light mode** (kľúče `topBar.theme.toDark` a `topBar.theme.toLight`). Volá `setColorScheme` z `useMantineColorScheme`, aktuálnu schému číta `useComputedColorScheme`.
- `MantineProvider` dostane `colorSchemeManager` (`localStorageColorSchemeManager`) a `defaultColorScheme='light'` (`DEFAULT_COLOR_SCHEME`). Voľba sa ukladá do `localStorage['mantine-color-scheme-value']` (predvolený kľúč Mantine, `COLOR_SCHEME_STORAGE_KEY`) a Mantine nastaví na `<html>` atribút `data-mantine-color-scheme="light|dark"`.
- Inline skript v `frontend/index.html` (obdoba `ColorSchemeScript` z Mantine pre aplikáciu bez SSR) nastaví atribút ešte pred prvým vykreslením, takže po reloade v tmavej schéme nebliká svetlá. Kľúč a predvolená hodnota sú v skripte napísané natvrdo, pri zmene `COLOR_SCHEME_STORAGE_KEY` alebo `DEFAULT_COLOR_SCHEME` treba zmeniť aj skript.
- Kým sa nenačíta JS aplikácie, má stránka v tmavej schéme pozadie z CSS Mantine (`#242424`), naše premenné vkladá `MantineProvider` až pri prvom rendri. Je to tmavé, svetlé bliknutie nevzniká.

### Ako písať CSS pre obe schémy

- V CSS moduloch a v props `c` / `color` použite premennú `--app-color-*` (`color: var(--app-color-muted)`, `c='var(--app-color-text-strong)'`), nie `slate.N`, `black` ani `white`.
- Nová farba, ktorá sa v schémach líši: pridajte premennú do `light` aj `dark` v `cssVariablesResolver` a riadok do tabuľky vyššie.
- Jednorazová úprava iba pre tmavú schému: selektor `[data-mantine-color-scheme='dark'] .trieda { … }` v CSS module. Natívne `light-dark()` funguje tiež (Mantine nastavuje `color-scheme`), ale premenné majú prednosť, aby boli hodnoty na jednom mieste.

## Testy

Unit testy bežia cez `vp test` v jsdom. `src/test/setup.ts` načíta matchery `@testing-library/jest-dom`, i18n a doplní `matchMedia`, `ResizeObserver`, `scrollTo`, `Element.scrollIntoView` (volá ho dropdown `Select`) a `document.fonts` (počúva ho `Textarea` s `autosize`), ktoré jsdom nemá. Po každom teste vyčistí `queryClient`, mock API, `localStorage` a vráti jazyk na `sk`.

- `renderApp(path)` (`test/renderApp.tsx`) vyrenderuje celú aplikáciu (Mantine s `env="test"`, Query, router s memory history) a vráti router.
- `mockApi(routes)` (`test/mockApi.ts`) nahradí adapter axios inštancie odpoveďami podľa kľúča `METHOD /url` (napr. `GET /auth/me`) a vráti zoznam odoslaných požiadaviek. Skratky `signedInAs(user)` a `signedOut()`, chyby cez `apiError(status, code)`.

## Prístupnosť

Cieľ sú základy WCAG 2.2 úrovne AA. Kontroluje ich rola `accessibility-reviewer` (`.agents/agents/accessibility-reviewer.md`) a dve automatické kontroly:

- **ESLint** `eslint-plugin-jsx-a11y` (config `recommended`) pre `frontend/**/*.tsx`, beží v `pnpm lint` a teda aj v `pnpm verify`. Vidí iba natívne JSX elementy (`img`, `a`, `div` s `onClick`, `autoFocus` …), Mantine komponenty (`Button`, `ActionIcon`, `Modal`) nekontroluje. Posledná verzia pluginu (6.10.2) deklaruje ako peer ESLint najviac 9; s ESLint 10 pravidlá fungujú, `pnpm install` iba vypíše varovanie o peer závislosti.
- **axe** (`@axe-core/playwright`) v E2E teste `e2e/tests/accessibility.spec.ts` skenuje vyrenderované obrazovky v svetlej aj tmavej schéme, viď [Testovanie](./testing.md#prístupnosť-axe).

Pravidlá v kóde:

- `document.title` je „{{page}} – Locale“ (kľúč `documentTitle`). Nastavuje ho `PageIntro` z nadpisu stránky cez hook `hooks/useDocumentTitle.ts`, takže sa mení s navigáciou aj s jazykom UI. Domovská stránka je zoznam projektov s titulkom **Projekty**.
- Notifikácie renderuje `AppNotifications` (`main.tsx`): Mantine `Notifications` s preloženým prístupným menom krížika (`notification.close`, Mantine ho bez `closeButtonProps` nemá). Notifikácia aj `Alert` majú `role="alert"`.
- Chyba z API pri poli (`400` `details`, `409 EMAIL_TAKEN`, `409 LANGUAGE_TAKEN`, `409 SLUG_TAKEN`) presunie fokus na prvé chybné pole (`setError(..., { shouldFocus: true })`, v **Pridať jazyk** na select), aby čítačka prečítala chybu. Chyby z klientskej validácie fokusuje React Hook Form sám (`shouldFocusError`).
- Po úspešnom **Skúsiť znova** v tabuľke používateľov, členov alebo jazykov dostane fokus tabuľka, v zozname projektov zoznam (`tabIndex={-1}`), lebo tlačidlo nahradia riadky. Na stránke Môj profil dostane fokus pole **Meno** (`ProfileForm` s `focusFirstField`).
- Theme má `respectReducedMotion: true`, pri `prefers-reduced-motion` Mantine vypne prechody.

Čo automatické kontroly nezachytia (poradie fokusu, návrat fokusu po modáli, zrozumiteľnosť textov, oznamovanie stavov), kontroluje `accessibility-reviewer` ručne podľa svojho checklistu.
