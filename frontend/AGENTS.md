# frontend

React SPA. Owner: `frontend-developer`. Details and examples: skill `frontend-conventions` (and `figma-to-code` for design work).

## Stack

Vite+ (`vp dev`, `vp build`, `vp test`), React 19, TypeScript strict, Mantine 9, Tailwind 4 (layout and spacing only), TanStack Router (code-based routes) and TanStack Query, axios, React Hook Form + zod, react-i18next (`sk` default, `en`).

## Structure (`src/`)

| Folder | Holds |
|---|---|
| `atoms/` | small reusable UI wrappers around Mantine (`Button`, `TextInput`, `Avatar`, …) |
| `components/` | composed components (`Layout`, `TopBar`, form fields, `Icons/` generated by SVGR) |
| `pages/` | route screens (`LoginPage`, `NotFoundPage`, …), one folder per page |
| `routes/` | TanStack Router route tree and guards |
| `api/` | axios instance, query keys, query and mutation hooks |
| `hooks/` | shared hooks, one per file (`useXxx.ts`) |
| `lib/` | `constants.ts`, `enum.ts`, `utils.ts`, i18n setup |
| `locales/` | `sk.json`, `en.json` (nested keys `page.form.field`) |
| `styles/` | Mantine theme, CSS variables, global CSS with layer order |
| `assets/` | `icons/` (source SVG for SVGR), fonts, images |
| `types/` | shared FE-only types |

## Rules

- A component folder contains `Component.tsx`, `types.ts` (props), optional `Component.module.css`. Default export, imported by full path (`@/atoms/Button/Button`). No barrel files except `components/Icons/index.ts`.
- Styling: Mantine theme and component overrides first, CSS modules second, Tailwind utilities only for layout and spacing. No inline hex colors; use theme or CSS variables.
- Contracts (schemas, DTOs, error codes, password rules) come from `@locale/shared`. Never redefine them here.
- Server state only through TanStack Query hooks in `api/`. Query keys only from `QUERY_KEYS`.
- HTTP only through the single axios instance (`baseURL: '/api'`). Never use absolute backend URLs.
- All texts via `t()`. API errors are translated by `code` (`errors.<CODE>`, `validation.<CODE>`), never by `message`.
- Use `type`, not `interface`. Enums and constants are `UPPER_CASE`.
- No lodash, no date library (use `Intl`).
